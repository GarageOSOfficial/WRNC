# WRNC Visual QA Checklist

Use against the release candidate. Record PASS/FAIL in Issue #44.

## All viewports
- [ ] Background foundation is `#080808` where specified.
- [ ] Full WRNC wordmark uses canonical Hyper Silver asset.
- [ ] Final C is complete and unclipped.
- [ ] Logo proportions and clear space are consistent.
- [ ] Headline decoration is neutral only.
- [ ] Primary CTA/action states use `#FF6400`.
- [ ] Purple `#7C3AED` appears only for product data/charts/selected/system states.
- [ ] No orange + purple decorative competition around headlines.
- [ ] Approved copy and claims are unchanged.
- [ ] Marketing -> auth -> workspace shell feels continuous.

## Desktop
- [ ] Hero product proof is legible and product-led.
- [ ] Header/logo alignment is consistent.
- [ ] Section gutters/rhythm show no obvious drift.
- [ ] CTA hierarchy is unambiguous.

## Tablet
- [ ] Stack/breakpoint transition does not create excessive whitespace.
- [ ] Product proof remains legible.
- [ ] Navigation/header remains usable.
- [ ] No clipping/overlap.

## 390px mobile
- [ ] No horizontal page overflow.
- [ ] No clipped headline/body copy.
- [ ] No clipped WRNC logo/final C.
- [ ] Primary CTA fits and remains tappable.
- [ ] Product proof stays within viewport.
- [ ] Auth fields/actions fit without horizontal clipping.
- [ ] Workspace cards and controls fit.
- [ ] Vehicle surface fits.
- [ ] Timeline fits.
- [ ] Documents fit.
- [ ] Add/create flows fit.

## Native/browser identity
- [ ] Favicon is approved and recognizable.
- [ ] iOS icon passes mask preview and has no transparency.
- [ ] Android adaptive foreground/background pass mask previews.
- [ ] Splash/launch artwork is centered, sharp, and clean on `#080808`.
