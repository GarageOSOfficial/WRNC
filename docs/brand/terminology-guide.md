# Terminology Guide

## Core terms

- WRNC: the product platform
- Build Passport™: flagship feature and summary experience
- Documentation Score™: scoring and completeness analysis feature
- Vehicle Workspace: the primary working context for a vehicle
- Mission Control: overview and navigation entry point

## Writing guidance

Use WRNC as the product name in all repository-facing materials. Avoid introducing legacy names into current documentation, workflows, or release messaging.
