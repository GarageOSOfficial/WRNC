# Branch Naming

## Branch naming convention

Use short, descriptive branch names that reflect the task type.

### Recommended patterns

- feature/<ticket>-<short-description>
- fix/<ticket>-<short-description>
- docs/<short-description>
- chore/<short-description>
- refactor/<ticket>-<short-description>

## Guidelines

- Use lowercase letters and hyphens.
- Keep names concise and specific.
- Include a ticket or issue number when available.
- Avoid vague names such as update, misc, or cleanup.
