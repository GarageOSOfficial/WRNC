# Repository Governance

## Purpose

This document defines the operating model for WRNC contributions, reviews, releases, and maintenance. It is the primary governance reference for contributors and maintainers.

## Scope

The governance model covers:

- repository contribution standards
- development workflow expectations
- review and release discipline
- maintenance practices for long-term stability

## Principles

- Keep changes focused and reviewable.
- Prefer clarity, safety, and maintainability over scope expansion.
- Preserve existing architecture and data contracts.
- Keep documentation and workflow guidance aligned with current practice.

## Roles

- Contributor: proposes changes and follows repository standards.
- Reviewer: evaluates correctness, scope, and completeness.
- Maintainer: approves merges and oversees release readiness.

## Governance expectations

- All changes should be traceable to a task, issue, or documented need.
- Documentation updates should accompany behavior changes when relevant.
- Pull requests should remain scoped to the requested work.
- Larger or cross-cutting changes should be discussed before implementation.
